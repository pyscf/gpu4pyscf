# AI Policy

GPU4PySCF permits the use of AI-assisted tools, including large language
models (LLMs), code-generation systems, and coding agents, subject to the
requirements below.

## Responsibility

You are responsible for any code you submit to GPU4PySCF's repository, regardless
of whether it was manually written or generated by AI. You must understand and
be able to explain the code you submit as well as the existing related code. It
is not acceptable to submit a patch that you cannot understand and explain
yourself. AI-generated code, comments, and other content must be reviewed and
verified before submission. Follow the
[contributing guidelines](CONTRIBUTING.md).

## Agent Guidance

We recommend using the
[agent-recipes provided by PySCF](https://github.com/pyscf/pyscf/tree/master/agent-recipes).
At the start of a task, ask your agent to read the repository's `AGENTS.md`,
the shared instructions, and the relevant templates:

- [Shared agent instructions](https://github.com/pyscf/pyscf/blob/master/agent-recipes/agents/AGENTS.md)
- [Coding-style template](https://github.com/pyscf/pyscf/blob/master/agent-recipes/skills/pyscf-coding-style.template.md)
- [PR-review template](https://github.com/pyscf/pyscf/blob/master/agent-recipes/skills/pyscf-pr-review.template.md)

Agents may not discover these resources automatically. Point them to the files
explicitly and apply the guidance to GPU4PySCF's code and development environment.

## Disclosure

You must disclose whether AI has been used to assist in the
development of your pull request, including which tool(s) have been used, and
a brief description of how they were used. Maintainers reserve the right to
reject pull requests that do not properly disclose AI use.


## Copyright

Contributors must ensure that submitted content complies with the project's
license requirements.

All code in GPU4PySCF is released under the [Apache License 2.0](LICENSE).

## Communication

When interacting with developers (forums, discussions, issues, pull requests,
etc.) do not use AI to speak for you, except for translation or grammar editing.
Communication with developers should reflect your own understanding and intent.
Human-to-human communication is essential for an open source community to thrive.

## AI Agents
The use of an AI agent that writes code and then submits a pull request autonomously is
not permitted. A human must review any generated code and submit a pull request according
to the 'Responsibility' section above.
